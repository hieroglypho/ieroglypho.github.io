The Egyptian “Alphabet”

Twenty-five signs, each standing for one consonant. Listen to each one, then keepKeep this page handy: you'll use these signs in every text you read.

Egyptian had about two dozen consonants, and each one could be written with a single sign. Egyptologists call these the one-consonant (uniliteral) signs. They are the closest thing Egyptian has to an alphabet, but scribes never used them as one. They mixed them freely with word-signs and multi-consonant signs, as you saw in Class 1.

The order matters. This is the order used by Egyptian dictionaries, including the one in Allen's grammar and the Hieroglyphica dictionary, so it's worth learning by heart. Press Play all a few times and it will start to stick.

About the sounds. No one has heard ancient Egyptian spoken, so its sounds are reconstructed. Each tile gives the conventional pronunciation Egyptologists use when they read aloud. Where we know the ancient sound was different (for example the throat sound of ꜥ), the note says so.

Use it

  • Learn the order: listen with your eyes closed, then try to say the next letter before it plays.
  • Learn the order: cover the page, say the letters in order, then check yourself.
  • Watch the look-alike sounds: h ḥ ḫ ẖ, s š, t ṯ, d ḏ. Beginners mix these up most.
  • Type them: in the course and in ΙΕΡΟΓΛΥΦΩ you can type the plain-keyboard codes A i a H x X S T D for ꜣ j ꜥ ḥ ḫ ẖ š ṯ ḏ.

Go deeper: Allen, Middle Egyptian (3rd ed.), §§2.1–2.3.
